# Recursos visuales

El logotipo tipográfico y el icono SVG son aproximaciones de desarrollo a la referencia proporcionada; sustituir por los archivos oficiales antes del lanzamiento.

Se descargaron seis fotografías ilustrativas desde Unsplash y se sirven localmente desde `public/images/food-1.jpg` a `food-6.jpg`. Las URLs de origen se conservan en `public/images/sources.json`. No se necesitan peticiones externas para mostrar el catálogo. Se corrigió la URL de la bebida, que devolvía HTTP 404.

Son fotografías de referencia, no fotografías de los platillos reales. Verifica las condiciones de uso y sustituye estos recursos por fotos propias antes de publicar comercialmente. La tarjeta SVG local de marca se mantiene como respaldo de errores.
